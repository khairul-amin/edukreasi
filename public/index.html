Untuk Sekolah

Satu platform untuk seluruh alur ujian

Admin, guru, proktor, dan siswa mendapatkan fungsi yang sesuai dengan perannya sehingga proses ujian lebih terkontrol dari awal sampai akhir.

01 · ADMIN

Kontrol Sekolah

  • • Dashboard sistem dan hasil ujian
  • • Kelola siswa, guru, mapel, jadwal & peserta
  • • Monitoring ujian dan pelanggaran
  • • Export Excel atau cetak PDF
02 · GURU / PROKTOR

Kelola Ujian

  • • Kelola mapel, soal, jadwal & token
  • • Tambah, edit, hapus & import soal dari Word
  • • Monitoring hasil per kelas dan mapel
  • • Export Excel dan PDF
03 · SISWA

Pengalaman Ujian

  • • Login sesuai kelas dan jadwal
  • • Timer dan navigasi soal
  • • Submit dengan proses terkontrol
  • • Skor langsung jika diaktifkan sekolah
Nilai Tambah

Pengelolaan ujian lebih rapi, cepat, terstruktur, dan menghemat waktu administrasi guru serta admin sekolah.

Pelaporan

Hasil ujian lebih mudah dipantau dan disiapkan untuk kebutuhan pimpinan sekolah maupun wali murid.

Teknologi & Infrastruktur

Fleksibel mengikuti kondisi sekolah

Dukungan mode online, jaringan lokal, dan cache perangkat untuk membantu ujian tetap berjalan pada berbagai kondisi koneksi.

🌐

Mode Online, On-LAN & Semi-Offline

  • • Online: sinkronisasi data melalui Google Sheets.
  • • On-LAN: ujian melalui server lokal sekolah.
  • • Semi-Offline: soal dan jadwal tersimpan di cache perangkat.
🛡️

Keamanan Ujian Anti-Curang

  • • Kiosk Mode dan lock task.
  • • Proteksi screenshot, screen recording, floating window dan split screen.
  • • Pengendalian gangguan aplikasi latar belakang saat ujian.
📱

Perangkat & Browser Khusus

  • • Deteksi root, emulator, USB debugging & developer options.
  • • Login hint, cookie sync, custom user agent dan interceptor.
  • • Auto-save dan sinkronisasi hasil ujian.
📡

Aktivasi & Monitoring

  • • Aktivasi melalui QR Code dan integrasi Google Sheets.
  • • Monitoring baterai, jam dan status pengiriman hasil.
  • • Token pengawas untuk proses unlock online maupun offline.
